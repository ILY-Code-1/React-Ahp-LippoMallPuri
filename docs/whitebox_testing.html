White Box Testing

Aplikasi Enerlyze — Smart Energy Analysis & AHP Decision Engine · Lippo Mall Puri
Pengujian struktural berbasis flowchart, flowgraph, cyclomatic complexity, dan basis path.

Pengujian white box difokuskan pada modul-modul inti yang memuat percabangan logika non-trivial — yaitu fungsi autentikasi, penyimpanan data dengan guard duplikasi, pembentukan matriks perbandingan berpasangan narasumber, dan pengecekan syarat Run AHP. Rumus yang dipakai: V(G) = E − N + 2P (E = jumlah edge, N = jumlah node, P = jumlah komponen terhubung) yang ekuivalen dengan V(G) = jumlah predikat + 1.

Fungsi 3 — buildMatrixFromPairs()

Code traceability: berkas src/lib/ahp.js baris 62–91 (pembentukan matriks perbandingan berpasangan resiprokal dari penilaian satu narasumber, beserta validasi nilai skala Saaty; memanggil isSaatyValue() baris 32–33).

3.1 Kode Sumber

 62  export const buildMatrixFromPairs = (criteriaCodes, pairs = []) => {
 63    const n = criteriaCodes.length
 64    const index = Object.fromEntries(criteriaCodes.map((c, i) => [c, i]))
 65    const matrix = Array.from({ length: n }, () => Array(n).fill(1))
 66    const seen = new Set()
 67  
 68    for (const p of pairs) {
 69      const i = index[p?.a]
 70      const j = index[p?.b]
 71      if (i === undefined || j === undefined || i === j) {
 72        throw new Error(`Pasangan kriteria tidak valid: ${p?.a} – ${p?.b}.`)
 73      }
 74      const value = Number(p.value)
 75      if (!isSaatyValue(value)) {
 76        throw new Error(`Nilai ${p.a} – ${p.b} harus pada skala Saaty 1/9..9.`)
 77      }
 78      const [lo, hi, v] = i < j ? [i, j, value] : [j, i, 1 / value]
 79      const key = `${lo}-${hi}`
 80      if (seen.has(key)) throw new Error(`Pasangan ${p.a} – ${p.b} diisi lebih dari sekali.`)
 81      seen.add(key)
 82      matrix[lo][hi] = v
 83      matrix[hi][lo] = 1 / v
 84    }
 85  
 86    const expected = (n * (n - 1)) / 2
 87    if (seen.size !== expected) {
 88      throw new Error(`Perbandingan belum lengkap: ${seen.size} dari ${expected} pasangan terisi.`)
 89    }
 90    return matrix
 91  }

Fungsi 4 — expertWeightsBlocker()

Code traceability: berkas src/lib/ahp.js baris 321–335 (pengecekan syarat Run AHP dari penilaian narasumber; dipanggil oleh runAndSaveAHP() di src/services/ahpService.js). Mengembalikan pesan penolakan, atau null bila Run AHP boleh dilanjutkan. Syarat kelengkapan data area diperiksa terpisah di runAndSaveAHP(), bukan di fungsi ini.

4.1 Kode Sumber

321  export const expertWeightsBlocker = (
322    { experts, combined },
323    { min = MIN_EXPERTS, max = MAX_EXPERTS } = {},
324  ) => {
325    if (experts.length < min) {
326      return `Run AHP ditolak: baru ${experts.length} narasumber berstatus final (minimal ${min}). Lengkapi penilaian di menu Master > AHP.`
327    }
328    if (experts.length > max) {
329      return `Run AHP ditolak: terdapat ${experts.length} narasumber final (maksimal ${max}). Hapus narasumber berlebih di menu Master > AHP.`
330    }
331    if (!combined.isConsistent) {
332      return `Run AHP ditolak: CR gabungan ${combined.cr.toFixed(3)} ≥ ${CR_THRESHOLD}. Tinjau ulang penilaian narasumber di menu Master > AHP.`
333    }
334    return null
335  }
